
Building Linux applications requires some tools that are not included
in the Flutter snap and need to be installed on your system:

  - clang
  - cmake
  - ninja
  - GTK 3 development files

To install them, run:

  sudo apt install clang cmake ninja-build g++ pkg-config libgtk-3-dev
